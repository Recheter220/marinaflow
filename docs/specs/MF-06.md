# MF-06 — Ficha da embarcação com histórico completo

`Onda 1` · `Estimativa 8 pt` · `TODO #2` · `Depende de MF-04`

> **Como** administrador, **quero** abrir uma embarcação e ver toda a sua vida na marina em uma única tela, **para** responder “o que já foi feito nesse barco?” sem cruzar filtros no histórico geral.

## Contexto

Hoje a consulta por embarcação existe como filtro em `/historico`, e mostra só a lista de serviços. A ficha reúne dados cadastrais, linha do tempo de serviços com fotos, galeria consolidada e um resumo. É também o destino do QR Code (MF-09), então a rota precisa estar estável antes daquela história.

## Requisitos funcionais

| ID | Requisito | Prioridade |
|---|---|---|
| RF-06.1 | Rota `/embarcacoes/{embarcacao}` exibe identificação, modelo, tipo, comprimento, ano, cliente responsável, situação e funcionário vinculado. | Alta |
| RF-06.2 | Linha do tempo em ordem decrescente de data de execução, com itens do serviço, executante, situação, observação e miniaturas das fotos. | Alta |
| RF-06.3 | Carrega 20 serviços por vez, com “carregar mais” — a ficha não puxa dez anos de histórico de uma vez. | Alta |
| RF-06.4 | Painel de resumo: total de serviços, data do último serviço, serviços em execução e os cinco tipos de serviço mais frequentes. | Alta |
| RF-06.5 | Galeria consolidada com todas as fotos da embarcação, mais recentes primeiro. | Média |
| RF-06.6 | Funcionário só abre a ficha de embarcação vinculada a ele; as demais respondem 403. | Alta |
| RF-06.7 | Há link para a ficha na tabela de embarcações e em cada linha do histórico. | Alta |
| RF-06.8 | Enquanto a linha do tempo carrega, a página mostra esqueleto animado em vez de área vazia. | Média |

## Contrato técnico

```
GET /embarcacoes/{embarcacao}   embarcacoes.show   (auth + ativo)

// EmbarcacaoController::show
return Inertia::render('EmbarcacaoFicha', [
    'embarcacao' => [...],                       // imediato
    'resumo'     => Inertia::defer(fn () => $this->fichas->resumo($embarcacao)),
    'servicos'   => Inertia::defer(fn () => $this->fichas->linhaDoTempo($embarcacao, $pagina))
                        ->merge(),               // "carregar mais" concatena
    'fotos'      => Inertia::defer(fn () => $this->fichas->galeria($embarcacao)),
]);

// app/Services/FichaEmbarcacaoService.php
public function resumo(Embarcacao $e): array;        // totais e agregados
public function linhaDoTempo(Embarcacao $e, int $pagina): array;
public function galeria(Embarcacao $e): array;

// Autorização: Embarcacao::query()->forUser($request->user())->findOrFail($id)
// — o scope existente já é a regra; não duplicar a checagem no controller.
```

## Critérios de aceite

**AC-06.1 — Ficha completa**
- **Dado** uma embarcação com 3 serviços e 4 fotos
- **Quando** o administrador abre a ficha
- **Então** vê os 3 serviços em ordem decrescente, as 4 fotos na galeria e os totais no resumo

**AC-06.2 — Visibilidade por papel**
- **Dado** um funcionário não vinculado à embarcação
- **Quando** ele acessa a URL da ficha diretamente
- **Então** recebe 404 e nenhum dado da embarcação chega ao navegador

**AC-06.3 — Consulta eficiente**
- **Dado** uma embarcação com 20 serviços, cada um com fotos
- **Quando** a linha do tempo é montada
- **Então** o número de consultas ao banco não cresce com a quantidade de serviços (asserção de contagem no teste)
