# MF-11 — Condição do tempo na marina (OpenWeather)

`Onda 3` · `Estimativa 3 pt` · `TODO #5` · `Depende de MF-08`

> **Como** gestor, **quero** ver a condição do tempo e do vento na marina ao abrir o painel, **para** antecipar se os serviços externos do dia são viáveis.

## Contexto

Serviço externo com chave paga por volume: a chamada é do servidor, com cache, e a chave nunca chega ao navegador. O widget é acessório — se a API falhar, o painel continua completo sem ele.

Vento em nó, não em metro por segundo: é a unidade que o pessoal da marina usa. A OpenWeather devolve m/s no sistema métrico; a conversão (× 1,94384) fica no serviço, não na tela.

## Requisitos funcionais

| ID | Requisito | Prioridade |
|---|---|---|
| RF-11.1 | O painel exibe condição atual, temperatura, sensação térmica, vento em nós e direção, para as coordenadas da marina. | Alta |
| RF-11.2 | Previsão resumida para os próximos 3 dias, com mínima, máxima e condição predominante. | Média |
| RF-11.3 | Alerta visível quando o vento passar de 20 nós ou houver previsão de chuva forte: “Condição desfavorável para operação externa”. | Média |
| RF-11.4 | Resposta cacheada por 30 minutos; o widget mostra o horário da última atualização. | Alta |
| RF-11.5 | Falha ou timeout da API oculta o widget e registra aviso em log — nunca derruba o painel. | Alta |
| RF-11.6 | Chave da API e coordenadas vêm de configuração, e a chave não aparece em nenhuma prop enviada ao navegador. | Alta |

## Contrato técnico

```
// config/services.php
'openweather' => [
    'key' => env('OPENWEATHER_KEY'),
    'lat' => env('MARINA_LAT'),
    'lon' => env('MARINA_LON'),
],

// app/Services/PrevisaoTempoService.php
/**
 * @return array{atual: array{temp: float, sensacao: float, condicao: string, vento_nos: float,
 *               direcao: string}, proximos: array<int, array<string, mixed>>,
 *               atualizado_em: string}|null
 */
public function paraMarina(): ?array;   // null em qualquer falha

// Prop diferida no painel — o widget é o último a chegar
'tempo' => Inertia::defer(fn () => $this->previsao->paraMarina()),
```

## Critérios de aceite

**AC-11.1 — Conversão de unidade**
- **Dado** a API simulada devolvendo vento de 10,3 m/s
- **Quando** o widget é montado
- **Então** exibe “20 nós” e o alerta de condição desfavorável

**AC-11.2 — Falha silenciosa**
- **Dado** a API simulada devolvendo 500
- **Quando** o painel é aberto
- **Então** o widget não aparece, os demais indicadores permanecem e há um aviso no log

**AC-11.3 — Chave protegida**
- **Dado** qualquer resposta do painel
- **Quando** as props são inspecionadas
- **Então** a chave da OpenWeather não aparece em nenhum lugar do HTML
