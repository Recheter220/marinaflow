# MF-09 — QR Code da embarcação e folha de etiquetas para impressão

`Onda 2` · `Estimativa 5 pt` · `TODO #9` · `Depende de MF-06, MF-07`

> **Como** funcionário no píer, **quero** apontar o celular para a etiqueta colada na embarcação e cair direto na ficha dela, **para** consultar o histórico sem procurar o barco na lista.

## Contexto

Depende da ficha (MF-06) como destino e do motor de PDF (MF-07) para a folha de etiquetas. O identificador do QR não deve ser o `id` sequencial: uma etiqueta é um objeto físico exposto, e um número sequencial convida a varrer o acervo. A história adiciona um ULID público à embarcação.

## Requisitos funcionais

| ID | Requisito | Prioridade |
|---|---|---|
| RF-09.1 | Toda embarcação tem um identificador público estável (ULID), gerado na criação; as existentes são preenchidas na migration. | Alta |
| RF-09.2 | `/e/{ulid}` encaminha para a ficha da embarcação correspondente. | Alta |
| RF-09.3 | Quem escaneia sem sessão ativa vai para o login e, ao autenticar, cai na ficha pretendida. | Alta |
| RF-09.4 | A ficha e a tabela de embarcações têm ação “QR Code”, que abre o código com opções de baixar SVG e imprimir. | Alta |
| RF-09.5 | Administrador gera folha A4 com etiquetas (nome, identificação e QR) de todas as embarcações ativas ou de uma seleção. | Média |
| RF-09.6 | O QR é gerado em SVG no servidor — sem chamada a serviço externo de geração de imagem. | Alta |
| RF-09.7 | Escanear a etiqueta de embarcação não vinculada, sendo funcionário, resulta em acesso negado — o QR não contorna a regra de visibilidade. | Alta |

## Contrato técnico

```
// migration: add_ulid_to_embarcacoes_table
$table->ulid('ulid')->nullable()->unique()->after('id');
// backfill: Embarcacao::whereNull('ulid')->each(fn ($e) => $e->update(['ulid' => (string) Str::ulid()]));
// depois: ->nullable(false) em migration subsequente ou via change()

// Embarcacao::booted() — creating: preenche o ulid quando ausente

GET /e/{embarcacao:ulid}          embarcacoes.qr        // redirect 302 para embarcacoes.show
GET /embarcacoes/etiquetas        embarcacoes.etiquetas // admin, PDF A4 grade 2 × 5

// Geração do SVG
$qr = new BaconQrCode\Writer(new SvgImageBackEnd(...));
$svg = $qr->writeString(route('embarcacoes.qr', $embarcacao->ulid));
```

> **Dependência aprovada em D-01:** `bacon/bacon-qr-code` — PHP puro, saída SVG, sem `imagick`. Ver [D-01](README.md#decisões-técnicas).

## Critérios de aceite

**AC-09.1 — Escaneamento autenticado**
- **Dado** um administrador logado
- **Quando** ele acessa `/e/{ulid}`
- **Então** é redirecionado para a ficha da embarcação correspondente

**AC-09.2 — Escaneamento sem sessão**
- **Dado** um visitante sem sessão
- **Quando** acessa `/e/{ulid}` e faz login
- **Então** chega à ficha pretendida, sem passar pela lista de embarcações

**AC-09.3 — O QR não fura a regra**
- **Dado** um funcionário não vinculado à embarcação da etiqueta
- **Quando** ele escaneia
- **Então** vê a negativa de acesso, sem qualquer dado da embarcação

**AC-09.4 — Folha de etiquetas**
- **Dado** 12 embarcações ativas
- **Quando** o administrador gera a folha
- **Então** recebe um PDF de 2 páginas, 10 etiquetas por página, cada uma com nome, identificação e QR legível
